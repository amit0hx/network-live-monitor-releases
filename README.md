Network Live Monitor keeps a live eye on servers, routers, printers, NAS boxes and cameras - anything with an IP address - from one clean dashboard, and alerts you the instant something goes offline.

## Download

Grab the latest installer from the **[Releases page](../../releases/latest)** and run it. It installs in seconds, needs no admin rights, and preserves your devices and logs across updates.

## What it does

- Live UP/DOWN monitoring with ping latency, uptime % and downtime history
- Its own clean application window
- Add, edit, reorder or bulk-import your devices (CSV / JSON)
- Desktop notifications and an offline alert sound, with one-click mute
- Event log viewer with CSV export and automatic weekly archives
- One-click in-app updates
